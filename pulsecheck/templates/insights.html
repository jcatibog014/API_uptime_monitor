What these mean
Uptime goal
How reliable a monitor should be (change it on the monitor). 99.9% allows 43 minutes down in {{ budget_days }} days.
Allowed downtime
That allowance (engineers call it an error budget). Failed checks spend it, counted like uptime: 99.95% up in {{ budget_days }} days spends 22 minutes. The bar shows what is left: green, amber under half, red when it is all spent.
Burn rate
How fast the last 24 hours spent it: 1× is exactly on pace, 10× would spend {{ budget_days }} days' allowance in {{ budget_days // 10 }}.
